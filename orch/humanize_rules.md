# 한국어 발행 텍스트 윤문 룰북

한 번의 모델 호출로 탐지, 윤문, 자체 점검을 끝내기 위한 짧은 기준표. 항목마다 "알아보는 법"과 "고치는 법"을 한 줄씩 적는다.

## 0. 손대지 않는 것

- 고유명사, 제품명, 모델명, 기관명
- 숫자, 날짜, 단위, 금액
- 큰따옴표 안 직접 인용
- 법령 조문, 수식, 코드, 파일 경로, URL
- 업계에서 그대로 쓰는 영어 약어 (API, GPU, LLM 등)

## 1. 번역 말투

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| T1 | "~에 대해", "~에 관하여" 가 목적어 자리를 대신함 | 조사 "을/를" 로 바꾸거나 동사를 바로 씀 |
| T2 | "~를 통해" 가 수단을 나타냄 | "~로", "~해서" 로 줄임 |
| T3 | "~하는 것이 가능하다", "~할 수 있게 된다" | "~할 수 있다" 또는 "~한다" |
| T4 | "~되어지다", "~게 되어지다" 같은 겹친 피동 | 능동형이나 단순 피동 한 번 |
| T5 | "가지고 있다" 가 소유가 아닌 속성을 말함 | "있다", "갖췄다" 처럼 짧게 |
| T6 | 사물 주어 + "~를 제공한다", "~를 가능하게 한다" | 사람이나 기능을 주어로 세워 직접 서술 |

## 2. 영어 섞기

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| E1 | 우리말로 충분한 낱말을 영어로 씀 (예: 인사이트, 임팩트, 레버리지) | 뜻이 같은 우리말로 바꿈 |
| E2 | 같은 개념을 한글과 영어로 번갈아 씀 | 처음 쓴 표기 하나로 통일 |
| E3 | 괄호 안 영어 병기가 문단마다 반복됨 | 첫 등장 한 번만 남김 |

## 3. 틀에 박힌 구성

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| S1 | 글 끝에 "결론적으로", "요약하자면" 으로 앞 내용을 다시 늘어놓음 | 반복 요약을 지우고 새 정보가 있는 문장만 남김 |
| S2 | 모든 문단이 "첫째, 둘째, 셋째" 같은 세 갈래 나열 | 실제 항목 수대로 쓰고 억지 셋 맞추기를 풂 |
| S3 | 문단 첫 문장이 질문으로 시작하고 바로 스스로 답함 | 답을 바로 서술 |
| S4 | "A 일 뿐만 아니라 B 이기도 하다" 가 거듭 나옴 | 두 문장으로 나누거나 "A 이고 B 다" |
| S5 | 원문에 없는 교훈이나 전망으로 마무리 | 지움. 의미를 더하지 않음 |

## 4. 습관처럼 붙는 문구

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| P1 | "시사하는 바가 크다", "주목할 만하다", "의미 있는 발걸음" | 무엇이 왜 중요한지 구체적으로 쓰거나 지움 |
| P2 | "혁신적인", "획기적인", "게임 체인저" 같은 근거 없는 찬사 | 사실 서술만 남김 |
| P3 | "다양한", "여러 가지", "폭넓은" 이 내용 없이 붙음 | 실제 대상을 쓰거나 지움 |
| P4 | "~라고 할 수 있다", "~라고 볼 수 있다" 로 끝맺음 | "~다" 로 단정 (원문이 단정한 경우만) |

## 5. 리듬과 끝맺음

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| R1 | 연속 세 문장 이상이 같은 어미로 끝남 | 어미를 섞되 원문 격식은 유지 |
| R2 | 문장 길이가 모두 비슷함 | 짧은 문장과 긴 문장을 섞음 |
| R3 | 한 문장에 쉼표로 이은 절이 네 개 이상 | 둘 이상의 문장으로 나눔 |

## 6. 군더더기

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| F1 | "매우", "정말", "굉장히" 같은 정도 부사가 겹침 | 하나만 남기거나 모두 지움 |
| F2 | 같은 뜻의 낱말을 나란히 씀 (예: 빠르고 신속한) | 하나만 남김 |
| F3 | "~하는 것", "~하는 부분", "~적인 측면" 이 뜻 없이 붙음 | 명사나 동사로 바로 씀 |

## 7. 얼버무림

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| H1 | 근거가 분명한 문장에 "~일 수도 있다", "~로 보인다" 를 붙임 | 원문 근거가 확실하면 단정 |
| H2 | 한 문장에 유보 표현이 둘 이상 | 하나만 남김 |
| H3 | 원문이 실제로 불확실하다고 말한 문장 | 유보 표현을 지우지 않음 |

## 8. 접속어

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| C1 | 문장마다 "또한", "더불어", "나아가" 로 시작 | 앞뒤 흐름이 분명하면 지움 |
| C2 | "하지만" 뒤에 실제 대비가 없음 | 지우거나 "그리고" 계열로 바꿈 |

## 9. 장식

| ID | 알아보는 법 | 고치는 법 |
|---|---|---|
| D1 | 이모지, 장식용 기호 | 지움 |
| D2 | 본문 곳곳의 굵게 강조 | 핵심 한두 곳만 남김 |
| D3 | 느낌표 연속 사용 | 마침표로 바꿈 |

## 자체 점검 (윤문 뒤 확인)

1. 0번 목록의 항목이 한 글자도 바뀌지 않았다.
2. 원문에 없던 사실, 비유, 평가를 더하지 않았다.
3. 원문의 격식(합쇼체, 해요체, 해라체)을 그대로 지켰다.
4. 문단 수와 순서를 바꾸지 않았다.
5. 바뀐 분량이 원문의 30% 를 넘지 않는다. 넘으면 고친 곳을 줄인다.
6. 출력에는 윤문한 본문만 있고 설명, 머리말, 코드펜스가 없다.
