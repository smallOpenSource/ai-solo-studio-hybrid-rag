# one_man_corp 프로젝트 개요

## 프로젝트 코드명과 목표

프로젝트 코드명은 **one_man_corp** (= 1인 기업)이다. 사용자가 직접 지정한 이름이며, 의미 불명 약어 사용이 금지된다. AI 기반 1인 기업 시스템을 온프레미스 단일 GPU(VRAM ≤12GB) 환경에서 구축하는 것이 핵심 목표다.

## 환경 전제

- **하드웨어**: 온프레미스 단일 GPU, VRAM ≤12GB
- **모델 방식**: 멀티모델 4bit(instruct 우선)
- **서빙**: llama.cpp/llama-swap, 네트워크 접근
- **운영 방침**: "느려도 OK" — 배치 처리·오프라인 1회 작업 허용

## 핵심 원칙 (불변)

1. **"회사·직원·협업"은 조직·인터페이스 메타포** — 멀티에이전트는 품질을 안 올린다(단일≥멀티). 직원 메타포는 전문화·조직화를 위한 것.
2. **품질 엔진 = 워크플로 우선 + BFCL 검증 모델 + GEPA 컴파일 + 비자기평가 에스컬레이션 + 검증/HITL** (단일 호출의 영리함이 아니라 구조+검증).
3. **검증된 것만 채택** — 취미 distill·소형모델 그래프추출처럼 실측이 무너지는 선택은 배제.
4. **통제는 위험기반·계획수준** — 전수 승인이 아니라 고위험만 게이팅 + 계획 일괄 승인 + 모니터·개입(human-on-the-loop).

## 연구 기반

v5 계획서는 2026-06-06~07 딥리서치 7라운드를 기반으로 한다 (총 ~759 에이전트, 182 소스 fetch, 892 주장 추출, ~175 적대 검증 → **128 확정 / 47 기각**). 적대 검증 통과만 "확정"으로 표기한다.
