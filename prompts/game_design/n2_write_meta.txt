앞 단계에서 설계한 게임 컨셉을 game/data/meta.json 파일로 기록해라. game_data_write 도구를 호출하되, path는 "data/meta.json"으로 하고 content는 아래 형태의 JSON 객체로 만들어라:

{
  "theme": "<테마 한 문장>",
  "title": "<게임 제목>",
  "coreLoop": "<코어 루프 설명>",
  "win": "<승리 조건>",
  "lose": "<패배 조건>",
  "continue": {
    "freeRetries": <정수 0 이상>,
    "costCurve": [<비감소 숫자 배열>],
    "sessionCap": <정수 1 이상>
  }
}

theme·title·coreLoop·win·lose는 비어있지 않은 문자열이어야 하고, continue.freeRetries는 0 이상 정수, continue.costCurve는 비감소 숫자 배열, continue.sessionCap은 1 이상 정수여야 한다.
