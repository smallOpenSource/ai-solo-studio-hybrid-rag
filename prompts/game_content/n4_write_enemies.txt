앞 단계에서 설계한 적 플레이버를 병합해 game/data/enemies.json 파일로 다시 기록해라. game_data_write 도구를 호출하되 path는 "data/enemies.json", content는 아래 형태의 JSON 객체로 만들어라:

{
  "enemies": [
    { "id": "<문자열>", "name": "<문자열>", "hp": <수치>, "speed": <수치>, "damage": <수치>, "spawnWeight": <수치>, "behavior": "chase|swarm|ranged|charger", "flavor": "<해당 적의 플레이버 한 문장>" }
  ]
}

★캐리포워드로 받은 기존 enemies의 모든 필드를 그대로 보존하고 각 항목에 flavor 키만 추가하라. id·name·hp·speed·damage·spawnWeight·behavior를 삭제하거나 값을 변형하지 마라(한 글자도 바꾸지 마라). 적 항목의 개수·순서도 읽어온 그대로 유지한다. flavor는 n3에서 그 id에 대응시킨 문장을 1개만 넣는다(중복 추가 금지). 결과는 validate_enemies가 ok:true가 되어야 한다(기존 필수 필드가 전부 보존돼야 통과한다).
