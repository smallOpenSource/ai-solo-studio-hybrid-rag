앞에서 설계한 무기 수치를 game/data/weapons.json 파일로 기록해라. game_data_write 도구를 호출하되 path는 "data/weapons.json", content는 아래 형태의 JSON 객체로 만들어라:

{
  "weapons": [
    { "id": "<문자열>", "name": "<문자열>", "fireRate": <수치 0 초과>, "projectiles": <정수 1 이상>, "damage": <수치 0 초과>, "range": <수치 0 초과>, "pierce": <정수 0 이상> }
  ]
}

weapons 배열은 최소 2개여야 한다.
