앞서 기록한 적·무기·웨이브·업그레이드 수치를 종합해 수치 범위를 검증하고 그 리포트를 game/data/balance.json 파일로 기록해라. game_data_write 도구를 호출하되 path는 "data/balance.json", content는 아래 형태의 JSON 객체로 만들어라:

{
  "survivalTargetSec": <수치 0 초과 — meta.win의 목표 생존 시간(초)>,
  "dpsCurve": [<비감소 숫자 배열 — 시간 경과에 따른 플레이어 누적 DPS 곡선>],
  "inRange": <불리언 — 모든 수치가 설계 범위 안이면 true>,
  "report": { "<검증 항목명>": <불리언> }
}

dpsCurve는 비감소(이후 값이 이전 값보다 작지 않음)여야 한다. report에는 수치 검증 항목별 통과 여부(예: enemyHpScaling·waveProgression·weaponBalance·upgradeEffectiveness)를 불리언으로 담아라. 모든 항목이 범위 안이면 inRange를 true로 한다.
