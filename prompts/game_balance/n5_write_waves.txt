앞에서 설계한 웨이브 수치를 game/data/waves.json 파일로 기록해라. game_data_write 도구를 호출하되 path는 "data/waves.json", content는 아래 형태의 JSON 객체로 만들어라:

{
  "waves": [
    { "tStart": <수치 0 이상>, "tEnd": <tStart보다 큰 수치>, "spawn": [ { "enemyId": "<enemies.json의 id 중 하나>", "rate": <수치 0 초과> } ], "difficulty": <수치 0 초과> }
  ]
}

waves 배열은 최소 2개, tStart는 오름차순(엄격 증가)이어야 한다. ★spawn의 enemyId는 반드시 앞서 기록한 enemies.json의 id 중 하나여야 한다(참조 무결성). 존재하지 않는 적 id를 쓰면 안 된다.
