# PRD — memoir-room (가제: 회상의 방 / Memoir Room)

> 장르: 코지 공간정리·배치 퍼즐 × 인생 내러티브 | 플랫폼: Steam(PC) 1차 | 가격 앵커: **$14.99**

## 1. 컨셉 / 핵심 루프

한 사람의 인생을 **여러 챕터의 "방"**으로 압축한다. 플레이어는 각 방에서 물건을 **올바른 자리에 배치**하며
공간을 정리하고, 정리가 끝나는 순간 **그 시절의 기억(서사 비트)**이 떠오른다. 기억의 끝에서 **선택지**가
주어지고, 그 선택이 다음 장과 결말의 톤을 바꾼다. 길을 잃지 않도록 **힌트 토글**로 정답 위치를 흐리게
비춰볼 수 있다(접근성).

핵심 루프(1 챕터):
1. **배치** — 물건을 끌어다(드래그) 또는 탭해서 골라 알맞은 슬롯에 놓는다. 틀린 자리는 거부된다.
2. **회상(서사 비트 + 비네트)** — 방의 모든 필수 슬롯이 채워지면 그 방에 얽힌 기억 텍스트가 출현한다.
   물건 하나를 제자리에 놓을 때마다 그 물건의 **한 줄 회상(비네트)**이 함께 떠오른다.
3. **선택(누적 분기·carry-forward)** — 물건/기억을 어떻게 할지 고른다. 선택마다 결과 서술이 달라지고,
   **초반의 선택이 누적되어 마지막 장(에필로그)의 톤을 바꾼다**.
4. **다음 방** — 다음 인생 챕터로 전환(공간·물건·기억이 진화).
* 보조: **힌트 토글** — 언제든 정답 위치 오버레이를 켜고 끌 수 있다.
* 분위기: **절차적 앰비언트 모티프** — 챕터마다 다른 모티프 성부열(정적 코드가 아닌 시간 엇갈림 시퀀스)로
  엮은 잔잔한 노스탤지어 드론. 챕터 distinct·순수(같은 챕터→같은 모티프)·비게이트 보조.

슬라이스 인생호(4챕터): **유년 → 학창 → 사회초년 → 현재(에필로그 장)**. 현재 방을 정리하면 누적 선택의
순수 합성으로 한 사람의 일대기 에필로그가 완성된다. 에필로그는 위치별 프래그먼트 합성에 더해 **선택 패턴
코다**(누적 선택의 *모양* — 일관/균형/전환 ≤3 티어·위치 무관 패턴 함수)를 덧붙여 결말의 결을 한 겹 깊게 한다.

차별 한 줄: "정리라는 손맛"과 "한 사람의 일대기"를 한 동작에 묶되, **인위적 게이팅 없이 길게**,
**길을 잃지 않게(힌트)**, **초반 선택이 결말로 이어지게(carry-forward)** 끌고 간다.

## 2. 차별화 — 시장 빈틈 3결함 직격

`market_analysis.md`(R2.2.1)의 적대검증을 통과한 **3가지 동시 결함**을 정면으로 겨냥한다:

| # | 시장 결함(경쟁작 반복 불만) | 본작의 직격 |
|---|------------------------------|-------------|
| ① | **볼륨 부재** — 서사 강한 코지작이 "가격 대비 짧다"(대부분 1.5~3h), 긴 작품은 인위적 게이팅 | **8~12h 유기적 볼륨** — 인생 8~10 챕터의 자연스러운 시간 흐름으로 분량을 "게이팅 없이" 확보 |
| ② | **퍼즐↔서사 균형 미완** — Unpacking·The Star Named EOS 정도만 균형, 그마저 "짧다" | 배치 퍼즐의 난이도 곡선과 서사 비트를 챕터마다 **교차 설계**(정리=감정의 트리거) |
| ③ | **힌트/가이드 부재** — 여성 30+·접근성 타깃 반복 불만, A Storied Life: Tabitha 실패 핵심 "무엇을 할지 모름" | **상시 힌트 토글**(정답 위치 오버레이)로 막힘 0·난이도 자기조절 |

경쟁 군집(시간민감): Unpacking(2021) → Whisper of the House(2025-08, 96%·~150k) → Hozy(2026-03,
~79~81%·~20만/$2.2M 3주) → A Storied Life: Tabitha(2026-04, 90min·"memoir choices nonsensical·no
hint"). ~12개월 내 니치가 빠르게 차고 있으나 **장편·서사심층 변종은 여전히 공백** → 본작의 창(window).

## 3. 타깃

- **1차**: 여성 다수/편향 · 코어 25~45세 · 접근성을 중시하고 **전투를 거부**하는 코지 플레이어층.
- **2차**: 내러티브 어드벤처(라이프시뮬·비주얼노벨) 교차층, "정리·수납" 콘텐츠 선호층.
- 플랫폼: Steam(PC) 1차 → 검증 후 Switch/모바일 포팅 고려(터치 1급 설계라 포팅 친화).

## 4. 가격 (근거)

- **$14.99** — 코지 프리미엄 밴드. Hozy/Whisper of the House $13~15 밴드에 정렬, Unpacking $19.99 보다 낮게.
- 근거: 코지 장르는 유닛당 가격 천장이 존재(>$20 는 "분량 대비 비싸다" 저항)하나, **솔로/소팀 BEP 가 낮아**
  $14.99 × 적정 판매로 흑자 도달이 현실적. 8~12h 볼륨이 "$14.99 대비 짧다" 불만(①)을 선제 차단.
- 할인 정책(가정): 출시 10% 런치 디스카운트 → 첫 메이저 세일 25% → 1년 후 33~40%.

## 5. 1년 매출 추정 (Steam · year-1)

> ★**가정 명시(필수)**: 아래는 **gross(소비자 지불 총액)** 기준 시나리오다. **실수령 net ≈ gross × 0.6**
> (Steam 플랫폼 30% + VAT/환불/지역가격 보정 ≈ 추가 ~10% 차감, 통상 0.55~0.65 → 0.6 중앙값 채택).
> 비교작 절대수치(Whisper ~150k·Hozy ~20만)는 **공개 추정치**이며 본작 보장치가 아니다(신규 IP·언검증).
> 전환 가정: **wishlist→sale** = 출시 1주 위시리스트의 ~10~20% + 1년 누적 ~20~30% 전환,
> **review→sale** = 리뷰 1건당 ~30~60 판매(코지 장르 중앙값). 마케팅/페스티벌 노출은 기본 시나리오에 포함.

| 시나리오 | 판매량(units, year-1) | **gross** | **net (×0.6)** | 가정/앵커 |
|----------|----------------------|-----------|----------------|-----------|
| **비관** | ~8~15k | ~$120k~220k | ~$72k~132k | 신규 IP 미검증 floor·노출 부진·니치 포화 |
| **기본** | ~40~70k | ~$600k~1.05M | ~$360k~630k | 위시리스트 ~3~6만·리뷰 ~1~1.5k·1 페스티벌 피처 |
| **낙관** | ~150~200k | ~$2.2M~3.0M | ~$1.32M~1.8M | Whisper(150k)·Hozy(~200k) 클래스 도달 시 |

- BEP(가정): 솔로~소팀(2~3인) 18개월 인건비+에셋 ~$150k~300k → **비관 net 하단에서도 BEP 근접**, 기본
  시나리오에서 명확한 흑자. (인건비 산정은 제작 로드맵 §8 확정 시 갱신.)
- 리스크 조정: 낙관치는 **상위 비교작이 90%+ 긍정·강한 입소문을 동반**한 결과 — 본작이 동급 품질·볼륨·
  폴리싱을 **모두** 충족할 때만 유효(아래 §6).

## 7. 프로토타입 범위 (= 슬라이스 AC 와 1:1)

> 본 슬라이스는 **풀게임이 아니다**. AC 가 천장이다(4챕터). 구현체 `games/memoir-room/index.html`,
> 검증 `web/scripts/play_memoir_check.mjs`(브리프 `vault/specs/memoir-room.md` 파싱→계약 파생).

| AC | 프로토타입이 증명하는 것 | 구현 훅 |
|----|--------------------------|---------|
| **AC1** 드래그/탭 배치 | 물건을 알맞은 슬롯에 놓으면 `placed[slot]=item`(틀린 자리는 거부) | `__placeItem` + 실입력 드래그(CSS 스케일 보정) |
| **AC2** 정리완료 → 서사 비트 | 전 슬롯 충족 시에만 `narrativeBeatShown=true`(창발·하드세팅 아님) | `__chapterComplete`·placeItem 내 결합 |
| **AC3** 챕터 진행 | 정리완료 게이트 통과 후 다음 챕터(방·물건·기억 진화) | `__advanceChapter` |
| **AC4** ≥1 선택지 → 분기 | 선택마다 다른 `branch` 결과 서술 | `__choose`(결정론 resolver·선택별 상이) |
| **AC5** 힌트 토글 | `hintOn` 반전 + 정답 위치 오버레이 표시/숨김(접근성) | `__toggleHint` |
| **AC6** 4챕터 인생호 | `totalChapters===4`(유년→학창→사회초년→현재)·ch1→4 순차·ch4 만 complete | `__advanceChapter`(루프) |
| **AC7** carry-forward | `choices[chapter-1]` 누적(idempotent)·`resolveEpilogue(choices)` 순수·**초반 선택(ch1·ch2)이 에필로그를 가른다** | `__choose`·`__resolveEpilogue`·`__resetGame` |
| **AC8** 아이템 비네트 | 배치 성공 시 `lastVignette===item.vignette`(아이템별 상이) + **노출 DOM 노드 렌더 소비** | `__placeItem`·`#vignette` textContent |
| **M-AC9** 챕터 앰비언트 모티프 | `__ambientPlan(chapter)` 순수·챕터 distinct(정적 코드→모티프 성부열) + 챕터 진입 시 앰비언트 성부 카운터가 plan 소비(계산만=hollow) | `__ambientPlan`·`__audio.voiceCalls.ambient`(소비 카운터) |
| **M-AC10** 에필로그 패턴 코다 | `resolveEpilogue` 가 선택 *패턴* 코다(일관/균형/전환 ≤3·위치 무관)를 가산 합성 — 기존 4-위치 합성·M-AC7 distinct 보존 | `__epilogueCoda`·`__resolveEpilogue` |
| C1/C2 | 콘솔 에러 0 · 모바일 실입력(탭/드래그) 동일 판정 경로 | console/pageerror·`page.mouse`+터치 |

★슬라이스가 **입증하는 차별축**: ②(정리=서사 트리거의 인과)와 ③(힌트)을 결정론으로 입증하고, R2 에서
**4챕터 인생호 + carry-forward(누적 선택→에필로그) + 아이템 비네트**로 서사 깊이(②)를 격상한다. 셋째 슬라이스는
가산으로 **챕터별 앰비언트 모티프(M-AC9)**와 **에필로그 패턴 코다(M-AC10)**를 더해 분위기·결말의 결을 한 겹 더
깊게 한다(신규 성부 0·코다 ≤3·bounded). ①의 완전한 8~12h 볼륨·실 OST·풀 분기트리는 여전히 슬라이스 범위 밖 →
**제작 로드맵으로 이월**(과대주장 차단·슬라이스는 4챕터·절차적 합성·파라메트릭만 주장).

## 8. 제작 로드맵 (슬라이스 → 풀게임)

1. **P1 — 콘텐츠 확장**: 4 → **8~10 인생 챕터**(유년·학창·사회초년·직장·가정·황혼…). 챕터 템플릿(배치 슬롯
   6~12 + 비트 + 비네트 + 분기) 양산 파이프라인. 목표 8~12h(①). 슬라이스가 4챕터 인생호 템플릿을 입증.
2. **P2 — 아트/연출**: 절차적 Canvas 도트 → **저작 픽셀아트 + 조명/분위기 연출**, 물건별 인터랙션 디테일,
   회상 컷신(②의 감정 곡선 강화).
3. **P3 — 서사 분기 심화**: 슬라이스의 **누적 선택→에필로그(carry-forward)**를 → 다층 분기 트리·다회차
   가치로 확장(슬라이스는 위치 프래그먼트 합성·풀 트리는 로드맵).
4. **P4 — 접근성/옵션**: 힌트 단계화·색맹/대비/텍스트크기·완전 마우스/완전 키보드·내레이션 자막(③ 완성).
5. **P5 — 오디오**: 절차적 → **저작 OST + 환경음**(노스탤지어 톤).
6. **P6 — 현지화·플랫폼**: 한국어 외 EN/JP 등, Steam 출시 → Switch/모바일 포팅(터치 1급이라 친화).
7. **P7 — 마케팅**: 데모/넥스트페스트로 floor 측정 → 위시리스트 전환·리뷰 데이터로 §5 추정 갱신.

> 범위 규율: 풀게임 항목은 **모두 본 로드맵 소관**이며 슬라이스(AC)에 끌어들이지 않는다(범위 폭주 방지).
